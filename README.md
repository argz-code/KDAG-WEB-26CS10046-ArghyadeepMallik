## About Me

Hi, I’m Arghyadeep Mallik, a first-year Computer Science and Engineering student at IIT Kharagpur. I am interested in web development, coding, and solving real-world problems through technology.

## About the Project

This project is a responsive landing page and registration form designed for the KDAG Beginner's Python & Data Analytics Bootcamp.

The website includes:
- A KDAG-themed landing page
- A separate registration form
- Name, Roll Number, Email, and Department fields
- JavaScript form validation
- Roll number validation
- Successful registration message
- Responsive CSS design

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Clean and user-friendly interface
- Responsive layout
- Basic JavaScript form validation
- Checks for empty fields
- Validates the roll number format
- Displays a registration success message after successful submission
